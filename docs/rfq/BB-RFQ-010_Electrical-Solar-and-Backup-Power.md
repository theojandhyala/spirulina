## 3. Backup power — a production-critical requirement

**Loss of pond circulation risks loss of the entire culture.** Within hours of
circulation stopping, biomass settles, the culture stratifies and oxygen
accumulates locally.

The following must be connected to backup supply:

| Load | Reason |
| --- | --- |
| **Paddle wheels, all four** | Culture loss |
| Control systems | Monitoring and alarms |
| Laboratory | Sample integrity |
| Emergency lighting | Safety |

Please quote a backup generator sized for these loads, with automatic changeover,
and state the changeover time.

## 4. Solar photovoltaic — quote separately

The daytime-weighted load profile suits solar generation well. Please quote:

| Option | Detail |
| --- | --- |
| Grid-tied system | Sized against the daytime load profile at § 1.1 |
| System size options | Please propose, with generation estimate and payback |
| Net metering | Advise on the position in Telangana |
| Mounting | Ground or roof; must not shade the cultivation ponds |
| Design life | 20–25 years per our design standard |

**Mounting position is constrained**: photovoltaic arrays must not shade the
ponds at any season, including at the winter solstice when shadows are longest.
Please allow for this in your layout proposal.
