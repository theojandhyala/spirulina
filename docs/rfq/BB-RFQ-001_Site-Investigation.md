### Subject: Topographical survey, geotechnical investigation and water analysis — BlueBloom Spirulina Production Facility, Hyderabad Region

BlueBloom Spirulina Private Limited is developing a commercial spirulina
production facility on a five-acre holding in the Hyderabad region of Telangana.
The first stage occupies one acre.

We invite your quotation for the site investigation work described below. This
is a **firm enquiry**: the scope is settled and we intend to place an order
against the successful quotation.

This work is on the critical path. Nothing else on the project can be designed
until it is complete, so please give particular attention to your programme.

## 1. Scope of supply

Three related packages. Please price each separately. You may quote for one, two
or all three, and please say which.

| Package | Description |
| --- | --- |
| **1A** | Topographical survey |
| **1B** | Geotechnical investigation |
| **1C** | Source water analysis |

## 2. Package 1A — Topographical survey

| Item | Requirement |
| --- | --- |
| Extent | The full five-acre holding, not only the first acre |
| Grid | 10 m maximum, closer where ground is irregular |
| Vertical accuracy | ±25 mm on hard surfaces |
| Datum | Establish a permanent benchmark on site |
| Features to record | Boundaries, existing structures, trees, services, access, drainage paths, adjacent ground levels |
| Deliverables | Drawings in CAD and PDF, point data, benchmark record |
| Registration | Survey to be carried out by a registered surveyor |

The full holding is required because the facility is designed to expand from one
acre to five, and the expansion layout must be set out against a single
consistent survey.

## 3. Package 1B — Geotechnical investigation

| Item | Requirement |
| --- | --- |
| Boreholes, building areas | Minimum 3, or 1 per 1,000 m² of built area, whichever is greater |
| Borehole depth | 1.5 × foundation width below founding level, or 3 m into sound rock |
| Trial pits, pond areas | 30 m grid, minimum 2.5 m depth or refusal |
| In-situ testing | Standard Penetration Test per IS 2131; plate load test per IS 1888 where warranted |
| Soil classification | Per IS 1498 |
| Laboratory testing | Per IS 2720 series |
| Groundwater | Standing level recorded, with an assessment of seasonal variation |

Laboratory testing to include, as a minimum:

- particle size distribution and Atterberg limits;
- **free swell index, at every trial pit**;
- shear strength;
- consolidation;
- compaction (Proctor);
- **permeability of the pond subgrade**;
- chemical testing per the table below.

### 3.1 Chemical testing

| Test | On | Purpose |
| --- | --- | --- |
| pH | Soil and groundwater | Concrete and buried-metal durability |
| Sulphate content | Soil and groundwater | Concrete exposure classification per IS 456 |
| Chloride content | Soil and groundwater | Reinforcement corrosion risk |
| Organic content | Soil | Foundation suitability |
| Resistivity | Soil | Buried-services corrosion protection |

### 3.2 Three matters requiring specific comment

Please make sure your report addresses each of the following explicitly. They
govern major design and cost decisions on this project:

| Matter | Why we need it |
| --- | --- |
| **Depth to rock** | Determines whether ponds are formed by cutting into grade or by building embankments above it. This changes the earthworks cost of the whole project. |
| **Expansive soil** | Seasonal shrink-swell would distort a shallow pond floor. Free swell index is required at every trial pit, not a sample of them. |
| **Groundwater level and seasonal range** | Governs uplift on an empty lined pond and buoyancy on below-grade structures. |

### 3.3 Deliverables

Factual report and interpretative report, including recommended safe bearing
capacity, recommended foundation type and founding depth, and comment on the
three matters above.

## 4. Package 1C — Source water analysis

Water is the principal process input to this facility and its quality determines
the water treatment plant, the culture medium formulation and the volume of
effluent produced. We need a complete picture, not a potability certificate.

| Parameter group | Determinands |
| --- | --- |
| General | pH, total dissolved solids, electrical conductivity, turbidity |
| Alkalinity and hardness | Total alkalinity, total hardness, calcium, magnesium |
| Anions | Chloride, sulphate, nitrate, fluoride |
| Metals | Iron, manganese, sodium, potassium |
| Heavy metals | Lead, cadmium, mercury, arsenic |
| Nitrogen | Ammonia, nitrate, nitrite |
| Microbiological | Total coliforms, *E. coli*, total plate count |
| Pesticides | Screen, if the catchment is agricultural |

| Item | Requirement |
| --- | --- |
| Sampling | From the intended source, by your personnel, with a record of sampling conditions |
| Repeat sampling | Please quote for one sample and for a repeat sample in a different season |
| Laboratory | NABL accredited |
| Deliverables | Full analytical report with methods and detection limits stated |

Please quote separately for borewell yield testing if you offer it.
